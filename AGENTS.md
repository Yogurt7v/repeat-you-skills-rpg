# Инструкции для агентов

Этот проект использует два файла инструкций:

- `PROJECT.md` — паспорт проекта (стек, архитектура, конвенции). 
  **Прочитай в первую очередь.**
- `MENTOR.md` — роль ментора и протоколы общения. 
  **Следуй ему, если ты выступаешь как ментор.**

Порядок приоритетов: `PROJECT.md` > `MENTOR.md` > текущий файл.
